# Roadmap Builder — Evaluation

Self-check before reporting completion. Mark each pass or fail.

- [ ] The correct mode (Draft / Update / Audit) was confirmed before proceeding
- [ ] The Product OS files relevant to the chosen mode were actually read this run, not assumed from memory (methodology always; template and draft-roadmap.md for Draft/Update; audit-roadmap-evidence.md for Audit)
- [ ] Every roadmap item is framed as an outcome/intent, not a feature (checked against the item-quality guidance in the methodology)
- [ ] Every Now/Next item cites a specific evidence file, or is visibly marked as unlinked/a bet
- [ ] Each item carries a confidence level independent of its lane
- [ ] An "Explicitly not doing" section is present (even if empty with a note why)
- [ ] For Update mode: the existing Review log was preserved and only appended to, never rewritten
- [ ] For Audit mode: no file was silently edited — findings were reported, not applied
- [ ] The proposed content (or audit findings) was shown to the user for review before any file write
- [ ] The terminal report matches the format in SKILL.md's Report step
- [ ] memory.md was updated with a run log entry
