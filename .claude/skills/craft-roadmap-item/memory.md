# Roadmap Item — Memory

Read at the start of every run. Update at the end.

## Learnings
- A short title and a specific summary are one job split across two fields (see methodology). Don't flag a title as vague in isolation if the summary already pins down what "better" means.
- Scope-boundary erosion tends to come via reframing, not a repeated blunt ask — a leading question or an appeal to urgency is the same placement request in different clothes. Treat framing changes as a signal to re-check the boundary, not as a new situation.
